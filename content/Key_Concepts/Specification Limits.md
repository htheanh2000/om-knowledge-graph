# Specification Limits

**Specification Limits** (Giới hạn kỹ thuật) là giới hạn do khách hàng hoặc kỹ sư đặt ra cho đặc tính sản phẩm: USL (Upper) và LSL (Lower).

## Giải thích
- Khác control limits: specification limits do bên ngoài quy định, control limits do quy trình quyết định.
- Process capability: so sánh spec limits với process variation.
- Cp = (USL - LSL) / 6σ; Cpk = min[(USL - μ) / 3σ, (μ - LSL) / 3σ].
