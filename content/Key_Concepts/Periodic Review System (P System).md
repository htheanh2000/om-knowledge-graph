# Periodic Review System (P System)

## Định nghĩa (Definition)
**Periodic Review System (P System)** (Hệ thống kiểm tra định kỳ) là hệ thống tồn kho **kiểm tra theo chu kỳ cố định** (P) và đặt hàng đủ để đưa tồn kho lên **mức mục tiêu (T)**.

## Giải thích (Explanation)
Quy tắc: **Cứ mỗi P đơn vị thời gian → Kiểm tra → Đặt hàng Q = T - IP**

Trong đó:
- **P** = chu kỳ kiểm tra (cố định, ví dụ: mỗi tuần)
- **T** = mức mục tiêu (Target level)
- **IP** = Inventory Position hiện tại
- **Q = T - IP** (lượng đặt thay đổi mỗi lần)

Đặc điểm:
- Thời gian đặt hàng **cố định**, lượng đặt **biến động**
- Không cần theo dõi liên tục → phù hợp hàng giá trị thấp ([[ABC Analysis|loại B, C]])
- Cần [[Safety Stock]] **nhiều hơn** Q System (vì phải bảo vệ trong P + L)
