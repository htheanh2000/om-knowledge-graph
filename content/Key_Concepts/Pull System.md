# Pull System

## Định nghĩa (Definition)
**Pull System** (Hệ thống kéo) là phương thức sản xuất trong đó **công đoạn sau "kéo"** (yêu cầu) sản phẩm từ công đoạn trước, dựa trên **nhu cầu thực tế**.

## Giải thích (Explanation)
So sánh Pull vs Push:
| | Push System | Pull System |
|---|---|---|
| Kích hoạt | Dự báo / lịch sản xuất | Nhu cầu thực tế / tín hiệu Kanban |
| Tồn kho | Thường cao (sản xuất trước) | Thấp (sản xuất khi cần) |
| Rủi ro | Dư thừa / lỗi thời | Thiếu hàng nếu không linh hoạt |

Trong Pull System:
- Chỉ sản xuất khi có **tín hiệu** từ công đoạn sau (thường qua [[Kanban]])
- Giảm **tồn kho bán thành phẩm (WIP)** → giảm [[Holding Cost]]
- Phát hiện vấn đề nhanh hơn (ít buffer che giấu lỗi)

Pull System là nguyên tắc cốt lõi của [[Just-in-Time (JIT)]] và [[Lean Systems]].
