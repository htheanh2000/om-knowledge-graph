# Linear Programming

## Định nghĩa (Definition)
**Linear Programming (LP)** (Quy hoạch tuyến tính) là phương pháp toán học để **tối ưu hóa** (maximize/minimize) một [[Objective Function|hàm mục tiêu]] tuyến tính, với các **ràng buộc tuyến tính**.

## Giải thích (Explanation)
Cấu trúc bài toán LP:
1. **Biến quyết định** (Decision variables) — cần tìm (x1, x2, ...)
2. **Hàm mục tiêu** ([[Objective Function]]) — maximize lợi nhuận hoặc minimize chi phí
3. **Ràng buộc** (Constraints) — giới hạn nguồn lực (nguyên liệu, nhân công, máy móc)
4. **Điều kiện không âm** — x1, x2 >= 0

Phương pháp giải:
- **Graphical method** — với 2 biến, vẽ vùng khả thi và tìm điểm tối ưu tại đỉnh
- **Simplex method** — thuật toán cho nhiều biến
- **Excel Solver** — công cụ thực hành

Ứng dụng: phân bổ nguồn lực, lập kế hoạch sản xuất, vận tải, pha trộn nguyên liệu.
