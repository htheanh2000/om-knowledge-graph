# Objective Function

## Định nghĩa (Definition)
**Objective Function** (Hàm mục tiêu) là hàm toán học cần **tối đa hóa** (maximize) hoặc **tối thiểu hóa** (minimize) trong bài toán [[Linear Programming]].

## Giải thích (Explanation)
Dạng tổng quát:
$$Z = c_1 x_1 + c_2 x_2 + ... + c_n x_n$$

Trong đó:
- Z = giá trị cần tối ưu (lợi nhuận, chi phí, thời gian...)
- c_i = hệ số (ví dụ: lợi nhuận/đơn vị sản phẩm i)
- x_i = biến quyết định (số lượng sản phẩm i cần sản xuất)

Ví dụ:
- **Maximize** Z = 5x1 + 8x2 (tối đa lợi nhuận)
- **Minimize** Z = 3x1 + 2x2 (tối thiểu chi phí)

Hàm mục tiêu luôn đi kèm với **constraints** (ràng buộc) — giới hạn nguồn lực, thời gian, nguyên liệu.

Giá trị tối ưu luôn nằm tại **đỉnh** của vùng khả thi (feasible region) — đây là tính chất cốt lõi của LP.
