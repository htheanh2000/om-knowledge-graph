# Continuous Review System (Q System)

## Định nghĩa (Definition)
**Continuous Review System (Q System)** (Hệ thống kiểm tra liên tục) là hệ thống tồn kho **theo dõi liên tục** mức tồn kho và **đặt hàng cố định Q đơn vị** khi tồn kho chạm [[Reorder Point]].

## Giải thích (Explanation)
Quy tắc: **Khi Inventory Position <= R → Đặt hàng Q đơn vị**

Trong đó:
- **Q** = lượng đặt hàng cố định (thường = [[Economic Order Quantity (EOQ)]])
- **R** = [[Reorder Point]] = d x L + [[Safety Stock]]

Đặc điểm:
- Q **cố định**, thời gian giữa các lần đặt **biến động**
- Cần hệ thống theo dõi liên tục (barcode, RFID, POS)
- Phù hợp với hàng hóa giá trị cao ([[ABC Analysis|loại A]])

So sánh với [[Periodic Review System (P System)]]: Q System cần ít [[Safety Stock]] hơn nhưng đòi hỏi theo dõi liên tục.
