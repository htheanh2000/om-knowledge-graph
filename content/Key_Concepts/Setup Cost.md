# Setup Cost

## Định nghĩa
**Chi phí thiết lập (Setup Cost)** là chi phí phát sinh khi chuẩn bị máy móc, dụng cụ để chuyển sang sản xuất lô sản phẩm mới.

## Giải thích
- Bao gồm: thời gian dừng máy, điều chỉnh, kiểm tra, lao động chuẩn bị
- Setup cost cao → khuyến khích sản xuất lô lớn để phân bổ chi phí
- Setup cost thấp → cho phép sản xuất lô nhỏ, linh hoạt hơn ([[Just-in-Time (JIT)]])
- Trong [[Economic Order Quantity (EOQ)]]: Setup cost tương đương Ordering cost
