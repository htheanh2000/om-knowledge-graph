# Statistical Process Control

**Statistical Process Control** (SPC - Kiểm soát quy trình thống kê) là phương pháp dùng thống kê để giám sát và kiểm soát quy trình.

## Giải thích
- Phân biệt: common cause variation (tự nhiên) vs assignable cause variation (bất thường).
- Control charts: X-bar, R, p, c -- phát hiện quy trình out-of-control.
- Quy trình in-control: chỉ có common cause variation, output dự đoán được.
