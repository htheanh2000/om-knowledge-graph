# Lot Size

**Lot Size** (Cỡ lô) là số lượng sản phẩm được sản xuất hoặc đặt hàng trong mỗi lần.

## Giải thích
- Lot size lớn: giảm setup cost nhưng tăng holding cost và WIP.
- Lot size nhỏ: linh hoạt hơn, giảm tồn kho nhưng tăng số lần setup.
- Phương pháp xác định: EOQ, Lot-for-Lot, POQ (Period Order Quantity).
