# Big Data

**Big Data** (Dữ liệu lớn) là tập dữ liệu khổng lồ được đặc trưng bởi 3V: Volume, Velocity, Variety.

## Giải thích
- **Volume**: khối lượng dữ liệu khổng lồ (terabytes, petabytes).
- **Velocity**: tốc độ sinh ra và cần xử lý dữ liệu (real-time, streaming).
- **Variety**: đa dạng loại dữ liệu (structured, unstructured, semi-structured).
- Trong operations: cải thiện forecasting, predictive maintenance, quality control.
