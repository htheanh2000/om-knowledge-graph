# Fixed-Interval Reorder System
**Fixed-Interval Reorder System** (Hệ thống đặt hàng theo chu kỳ cố định) - Hệ thống kiểm kê định kỳ, đặt hàng theo khoảng thời gian cố định với số lượng thay đổi.
