# Multiple-Server Model

**Multiple-Server Model** (Mô hình nhiều server, M/M/s) là mô hình hàng đợi với s server phục vụ song song.

## Giải thích
- Giả định: Poisson arrival, exponential service, s servers giống nhau.
- Tính: xác suất hệ thống trống (P0), thời gian chờ trung bình (Wq), số khách chờ trung bình (Lq).
- Khi thêm server: giảm thời gian chờ nhưng tăng chi phí -- cần cân bằng.
